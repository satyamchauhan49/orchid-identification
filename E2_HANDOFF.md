## Training configuration

All three runs used the grouped manifest in commit `ba3ca57`, ImageNet-pretrained torchvision ResNet-18, seed 42, AdamW with learning rate and weight decay both 0.0001, batch size 32, 2 data-loader workers, shuffled training, a maximum of 15 epochs, and early stopping patience of 4. The training objective is the mean of the seven head losses. The checkpoint is chosen by minimum plain validation cross-entropy, including for the smoothed runs.

Training uses a 224-pixel random resized crop with scale 0.75–1.0 and a random horizontal flip. Inference resizes the shorter edge to 256 pixels, center crops to 224, converts the RGB image to a tensor, and applies the saved training-only normalization. HSV adds three 16-bin histograms from the same image crop to the CF and CL heads.

## Load an HSV checkpoint

The code in `models_resnet/model_hsv_colab.py` is identical to the module generated by both HSV notebooks. From the repository root, load a trusted checkpoint shared by the team as follows.

```python
import sys
from pathlib import Path

import torch

sys.path.insert(0, str(Path("models_resnet").resolve()))
from model_hsv_colab import OrchidHSVResNet18

checkpoint = torch.load("best.pt", map_location="cpu", weights_only=True)
model = OrchidHSVResNet18(
    checkpoint["num_species"],
    checkpoint["feature_classes"],
    pretrained=False,
    mean=checkpoint["mean"],
    std=checkpoint["std"],
)
model.load_state_dict(checkpoint["model_state_dict"], strict=True)
model.eval()
```

For label smoothing without HSV, instantiate `OrchidMultiTaskResNet18` from `models_resnet/model.py` with the saved species count, feature-class counts, and `pretrained=False`.

## Validation comparison

Label smoothing led on GreenYellow recall (81.58%) and species top-1 accuracy (76.43%). HSV led on Panicle recall (68.97%) and validation loss (0.3994). HSV with smoothing led on CL macro-F1 (82.99%). Use the calibration and validation exports to compare these trade-offs in the downstream resolver before selecting a final model.
