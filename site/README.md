# Local results website

The source is template.html. Generate the standalone site using models_other.release,
or use models_other.finish_demo for the prepared example workflow.
Open outputs/demo_delivery/site/index.html to explore the complete local demo.

The output uses plain HTML/CSS/JavaScript and copied local images: no backend,
external font, analytics, package manager or network connection is needed to view it.
Metric selector, stage filters, image-head selector, expandable details and downloads
work when opened directly. Demo banners distinguish scores from real orchid claims.

Publication is not performed. Follow SNEHA_NEXT_STEPS.md for real inputs and deployment.
